🗄️ Database

AspNetUsers (ApplicationUser)
  • PK Id
  • UserName, Email
  • HoTen, DiaChi
  • PhoneNumber
  • → Carts, Orders, Reviews
  • → CustomerNotifications
Categories
  • PK Id
  • Name, Description
  • DisplayOrder, IsVisible
  • → Products
Products
  • PK Id
  • Name, Description
  • Price, DiscountPrice
  • Stock, ImageUrl
  • IsAvailable, IsFeatured, IsVisible
  • FK CategoryId
  • → Carts, OrderDetails, Reviews
  • → ProductImages, ProductSpecifications, Warranties
Orders
  • PK Id
  • OrderDate, Status
  • TotalAmount, PaymentMethod
  • FullName, PhoneNumber, Email
  • ShippingAddress, Note
  • FK UserId
  • → OrderDetails
  • → AdminNotifications, CustomerNotifications
OrderDetails
  • PK Id
  • Quantity, UnitPrice
  • IsReviewed
  • FK OrderId
  • FK ProductId
Carts
  • PK Id
  • Quantity, UnitPrice
  • AddedDate
  • FK UserId
  • FK ProductId
Reviews
  • PK Id
  • Rating (1-5), Comment
  • CreatedDate
  • FK ProductId, UserId, OrderId
Promotions
  • PK Id
  • Name, Description
  • DiscountType, DiscountValue
  • StartDate, EndDate, IsActive
  • ⚠ Chưa liên kết với Order
AdminNotifications
  • PK Id
  • Title, Message, Type
  • IsRead, CreateDate
  • FK OrderId
CustomerNotifications
  • PK Id
  • Title, Message, Type, Link
  • IsRead, CreateDate
  • FK UserId, OrderId
ProductImages
  • PK Id
  • ImageUrl, DisplayOrder, IsDefault
  • FK ProductId
ProductSpecifications
  • PK Id
  • SpecName, SpecValue, DisplayOrder
  • FK ProductId
Warranties
  • PK Id
  • WarrantyPeriod (tháng)
  • Description, Terms
  • FK ProductId

🔧 Cần làm thêm

🔴 Ưu tiên cao
  • Bootstrap/jQuery thiếu file — wwwroot/lib/ chỉ có LICENSE, cần libman restore
  • Admin Edit danh mục — thiếu Edit.cshtml trong Areas/Admin/Views/Category
  • Tích hợp Promotion — bảng đã có nhưng chưa áp dụng khi checkout
  • Thanh toán online — hiện chỉ COD, cần VNPay / MoMo / ZaloPay
🟡 Ưu tiên trung bình
  • ProductImage & Specification — entity có, seed có, chưa hiển thị trên trang chi tiết SP
  • Warranty — entity có nhưng chưa hiển thị
  • Phân trang Admin — danh sách SP/đơn hàng/user chưa có phân trang
  • Tìm kiếm Admin — chưa có filter trong các trang quản lý
  • Upload ảnh sản phẩm — hiện chỉ nhập URL thủ công
  • Email xác nhận đơn hàng — EmailSender có nhưng chưa gọi sau checkout
  • Quên mật khẩu — ViewModel có nhưng chưa implement flow reset
🟢 Ưu tiên thấp
  • Thống kê doanh thu — Dashboard hiện là placeholder
  • Xuất báo cáo — Excel/PDF đơn hàng
  • Wishlist — danh sách yêu thích
  • So sánh sản phẩm
  • SEO — meta tags, sitemap
  • Responsive Admin — _AdminLayout chưa tối ưu mobile
